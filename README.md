## Как пользоваться

Из-за заметного размера HTML-файлов удобнее смотреть материалы в браузере (локально или как статические страницы), а не в превью больших файлов.

1. Скачайте или клонируйте репозиторий и откройте нужный `Notebook.html`/`Notebook2.html` напрямую в браузере.
2. Если удобнее открывать через локальный адрес, запустите статический сервер из корня репозитория:

```bash
python -m http.server 8000
```

После запуска откройте в браузере `http://localhost:8000/` и перейдите к нужному HTML-файлу.

## Ограничения и замечания

- Материалы в репозитории — это сохранённые результаты выполнения ноутбуков в формате HTML.
- Исходные `.ipynb`, отдельные скрипты, `requirements.txt` и автоматические тесты в текущем репозитории не обнаружены.
- Для повторного запуска экспериментов исходные ноутбуки и зависимости нужно подготовить отдельно.
